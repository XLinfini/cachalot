# 论文问答

[文档目录](../README.md) · 相关：[模型与 OCR](models-and-ocr.md)、[数据与缓存](data-and-cache.md)

问答栏是本体功能，独立于选区翻译插件。论文与会话在本地保存，发送问题时相关文字、历史消息和适用的用户附图会提交给所选模型服务。

## 发起问题与选择模型

打开论文后，在右侧输入问题并发送。模型菜单位于发送按钮左侧，向上展开，先选择服务商，再选择已经添加的模型。目录接口返回的可选模型不会自动成为已添加模型。

适合从明确范围开始，例如“请解释第 3 页的控制结构，并注明依据页码”。当前页会参与文字相关性排序；当前选区的文字也可加入问题背景。

## 当前检索方式

问答使用本地页面文字的轻量检索，选取最多 3 页，每页最多 7,000 个字符，再附上最近最多 12 条历史消息。它不是向量数据库或全文一次性发送；页面尚未索引时会向模型说明文本缺失。

当前系统提示要求用简体中文回答并尽量标注页码。界面语言与回答语言不是同一个设置。引用与结论仍需在原文中核对，尤其是多个相近术语、跨页论证与数学推导。

本体不会自动把所有 PDF 页面的图表图片发送给模型。需要讨论图像时，可上传自己的截图。

## 附图与模型能力

输入框左下角的“+”支持 PNG、JPEG、WebP 和 GIF，多选时单张文件最大 10 MiB。模型是否支持图片按具体模型配置，不从名称自动判断。

| 状态                     | 行为                                         |
| ------------------------ | -------------------------------------------- |
| 当前模型支持图片         | 可以附图，图片随消息保存并参与请求           |
| 当前模型为文字模型       | 上传按钮禁用并提供提示；历史图片在请求中省略 |
| 草稿含图片后改选文字模型 | 保留草稿，阻止发送，需移除图片或改回图像模型 |
| 再改回图像模型           | 已保存的图片可再次参与历史上下文             |

省略历史图片不删除本地图片，软件会提示模型不要猜测图像内容。

## 会话与运行状态

问答支持历史会话、编辑、复制、重新生成和删除。删除论文会同时移除对应会话；仅清理缓存不会删除会话或图片。

打开设置、安装插件和重启插件不会卸载本体聊天或取消其等待中的请求。关闭聊天、切换论文等本体操作可能卸载聊天 UI；当前本体问答没有统一的底层请求取消入口，UI 关闭不代表 HTTP 已中止。这与插件视图的请求取消机制不同。

故障排查见[模型请求与图片](troubleshooting.md#模型请求与图片)。实现入口是 `src/application/paper-assistant.ts`。
