# PDF 排版与宏包

[文档目录](../README.md) · [插件管理](extensions.md) · [开发接口](../extension-api/typesetting.md)

在设置中选择 **PDF 排版**，管理本体的私有 XeLaTeX。排版服务供生成 PDF 的插件使用；本体仍是阅读器，全文翻译插件尚未预装。编译、初始化或宏包安装不会要求重启阅读器。

当前支持 Linux x86-64 桌面版。浏览器提供阅读预览并显示排版需要桌面版；Windows、macOS 和其他架构尚未提供运行时与隔离适配。

## 内置运行时

选择“内置 TeX Live”并保存。首次编译会自动把随安装包提供的资源解压到应用数据的 `typesetting/runtimes/<runtimeId>`，也可点击“初始化运行时”提前完成。基线使用冻结的 TeX Live 2025 final，包含 XeLaTeX、xdvipdfmx、kpsewhich、tlmgr、中文/数学宏包与字体；不修改系统 PATH，不要求安装系统 TeX。

Linux 需要 bubblewrap、Perl 和标准字体/C 运行库。Deb 包声明这些依赖；其他包装形式需要系统事先提供，内置 TeX 文件不替代内核与这些系统依赖。bubblewrap 还需可用的用户命名空间。隔离失败会在日志显示错误，不会自动改成无隔离编译。

## 安装宏包和添加文件

在“宏包名称”中输入 TeX Live 包名，例如 `booktabs microtype`，用空格或逗号分隔，再点击“安装宏包”。它们从同一冻结仓库安装到设置中显示的用户目录，以 tlmgr user mode 管理。网络只用于用户主动安装，不用于普通编译。安装日志可选取复制，失败会保留原因。

tlmgr user mode 只支持可迁移到用户树的包；需要更新引擎、系统格式或非用户包的情况使用外部 TeX Live，在其管理工具中处理。软件不自动跨年份升级或更新用户宏包。取消安装会终止该次 tlmgr 与子进程；已成功安装的包会保留，重新安装可由 tlmgr 继续核对。

需要 shell escape 或额外外部工具的宏包不在当前支持范围；外部运行时模式也保持同样的隔离和 shell escape 限制。

用户目录采用标准 TEXMF 布局，例如 `tex/latex/my-package/my-package.sty` 或 `fonts/opentype/my-font/font.otf`。模板目录中的 `.tex` 可由插件模板使用 `\input{模板名称}`；编译时只读。添加字体或模板后直接发起新编译即可；不要把用户文件写入版本化的基线运行时。

升级 Cachalot 会切换新的基线目录，保留用户宏包、字体和模板。用户树按 TeX Live 年份隔离；未来跨年份升级需要另行设计迁移，不能直接承诺旧宏包一定兼容新引擎。卸载应用时系统对应用数据的处理仍由安装方式决定。

## 外部运行时

选择“外部 TeX Live”，输入其 `bin/x86_64-linux` 目录并保存。需要可独立使用的 TeX Live 树，包含 xelatex、xdvipdfmx、kpsewhich、tlmgr 及预生成的 xelatex 格式。外部树在隔离中挂载，分散在系统目录的发行版 TeX 安装不适用当前适配。

两种模式都使用本体的独立任务目录、取消和隔离机制。外部宏包由用户用该版本的 tlmgr 管理，软件里的安装按钮仅服务内置 2025 用户树。建议使用相同年份以避免用户包与引擎不兼容。

## 排查

| 现象 | 处理 |
| --- | --- |
| 运行时资源包缺失 | 源码开发先运行 `npm run texlive:prepare`；使用已带资源的桌面安装包 |
| 缺少 bubblewrap/命名空间不可用 | 安装系统依赖，检查系统用户命名空间策略；保留错误日志 |
| `File …sty not found` | 安装该宏包或核对用户 TEXMF 目录；普通编译不会自动下载安装 |
| 中文字体缺失 | 模板使用内置 `fontset=fandol`，自定义字体使用明确的字体文件 |
| 源码、字号、盒子或超时错误 | 交由插件修正模板、目标布局或任务时限；宿主不自动替换译文或缩小公式 |

排版输出由插件保存为产物或显示在右侧比较视图；右侧 PDF 仍为被动阅读，不复用原文分析。
