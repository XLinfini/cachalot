# 常见问题与排查

[文档目录](../README.md) · 开发诊断：[开发与贡献](../development.md)

先记录发生问题的操作、当前页、所选模型与错误文本，再按下表定位。保留原始 PDF 和安装包；插件问题优先使用插件重启，不把重启本体或清除整个站点数据当作安装步骤。

## 阅读与分析

| 现象                     | 先检查                                                         | 处理与边界                                                            |
| ------------------------ | -------------------------------------------------------------- | --------------------------------------------------------------------- |
| PDF 能显示但没有可选文字 | 是否纯扫描页，或文字编码异常                                   | 当前没有扫描件全文 OCR；显示能力与文字提取是不同阶段                  |
| 框选后没有翻译动作       | 当前页版面是否完成，完整单元是否全部进入蓝框，翻译插件是否停用 | 扩大范围直到出现紫色命中框，或使用精确文字模式                        |
| 版面、公式或顺序不对     | 打开“版面”对照原 PDF                                           | 检测和语义是推断，文字模式可绕开部分选择问题，不保证修复结构          |
| 模型文件缺失或校验失败   | `public/models/` 与构建/运行错误                               | 源码环境执行 `npm run models:prepare` 后重试，不能替换为任意同名 ONNX |
| 缓存恢复出现错误         | 是否旧版本或存储被阻止                                         | 查看具体错误，关闭论文后重开；按类别清理可再生缓存                    |
| 没有目录                 | PDF 是否自带 outline                                           | 当前目录来自 PDF 元数据，不是自动生成的文档语义大纲                   |

源码运行模型脚本遇到 `ERR_UNKNOWN_FILE_EXTENSION`、TypeScript 语法错误时，先核对 Node 版本。推荐 Node 24.x；只满足 Vite 的较低版本要求不足以运行所有脚本，详见[环境准备](../get-started.md#准备环境)。

## 模型请求与图片

| 现象                     | 先检查                                    | 处理                                                                              |
| ------------------------ | ----------------------------------------- | --------------------------------------------------------------------------------- |
| 服务商 401/403           | 密钥、账号权限、所用区域与地址            | 修正配置，阅读脱敏错误正文；不要在反馈中附真实密钥                                |
| 404 或 HTML 错误页       | 实际请求地址及代理路径                    | 对照[地址规则](models-and-ocr.md#api-地址如何解释)，核实 Chat 与 OCR 协议是否匹配 |
| `/models` 获取失败       | 服务是否支持目录                          | 手工添加准确的模型 ID；目录失败不等于生成接口一定不可用                           |
| 浏览器失败而桌面正常     | DevTools 是否报告 CORS                    | 由服务商允许相应 origin，或使用桌面传输；插件权限不能修复 CORS                    |
| 无法上传图像或草稿被阻止 | 当前具体模型的图像能力                    | 改选有能力的模型或移除草稿图片；能力标记不改变服务实际能力                        |
| 刷新后找不到配置         | origin、端口、profile、隐私会话及存储错误 | 回到原来的数据环境，确认保存成功；密钥保存失败不会报告成功                        |

## 翻译与公式

| 现象                             | 处理                                                       |
| -------------------------------- | ---------------------------------------------------------- |
| 提示公式标记缺失、重复或顺序改变 | 对照选区与结果后重试；不要把结构错误的输出直接当作成功译文 |
| 独立 OCR 请求失败                | 检查 OCR 的接口类型、模型、地址、密钥及原始业务错误        |
| 无图像能力可用于回退             | 配置独立 OCR 或选择实际支持图片的模型；可保留原公式图      |
| 公式只显示图片                   | 部分选取、缺少可靠候选或校验失败时，这是来源保留行为       |
| OCR 候选看似完整却不正确         | 手工与原 PDF 核对；语法检查不保证数学正确                  |
| 术语或背景不一致                 | 检查文档覆盖状态与提示词；背景不保证跨次翻译统一术语       |

## 插件安装与运行

| 提示 / 现象                         | 处理                                                                          |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| 缺少依赖包                          | 在当前预览补充相应 ID 的本地包；不会自动在线下载                              |
| 循环依赖                            | 检查提示路径，需要作者修正清单；反复重启不能解决                              |
| 依赖已停用                          | 启用消费者会联动启用其已安装依赖                                              |
| `engines.cachalot` 不兼容           | 使用适配当前 API 的版本，不能仅修改清单绕过真实 API 差异                      |
| 内置插件不能替换 / 卸载             | 内置身份由本体决定；外部包不能覆盖选区翻译                                    |
| 同批选择了两个版本                  | 每个 ID 留一个版本，再确认安装                                                |
| 安装成功但没有视图                  | 检查激活事件；打开论文，或查看是否关闭了该视图                                |
| Worker 不响应或插件错误             | 重启该插件，观察消费者是否恢复；需要时安装修复版本                            |
| 被拒绝的能力或未声明贡献            | 作者应在清单与 SDK 注册中保持一致，见[清单参考](../extension-api/manifest.md) |
| 尝试访问 DOM、Tauri、Node、任意网络 | 改用受支持 SDK 与 Tree/Webview；社区运行时没有这些权限                        |

## 反馈所需信息

给出应用提交或版本、桌面/浏览器及平台、界面语言、重现步骤、相关插件 ID/版本和脱敏错误。版面问题优先给出具体页码与可以公开分享的最小 PDF；服务商问题附接口类型和实际请求路径即可，不附密钥或私人全文。

开发者还应说明开发预览还是生产构建。Chromium 测试通过不能代替目标桌面 WebKit 或 iPad 真机验证。
