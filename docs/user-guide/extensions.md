# 插件管理

[文档目录](../README.md) · 开发者入口：[插件开发](../extensions.md)

## 当前安装来源

“设置 → 插件”支持本地 `.cachx` 或 ZIP 包，一次可选择多个。`.cachx` 是 Cachalot 的 ZIP 包格式，不是 VS Code `.vsix`；不能通过改后缀安装 VS Code 插件。当前没有市场、在线依赖下载、自动升级或签名验证。

只安装你信任的发布者提供的包。权限预览说明插件可以通过宿主读取什么或调用什么，SHA-256 记录内容不等于验证发布者身份。

## 安装与补齐依赖

1. 点击“从插件包安装”，选择包。
2. 查看 ID、版本、权限、依赖、插件组合和受影响的运行插件。
3. 缺少依赖时点“补充依赖插件包”，选择提供者或组合成员的本地包。可一次多选。
4. 确认缺包与循环提示已经解决，再点击安装。

同一批次中每个插件只能选一个版本；再次补充一个相同 ID 的包可替换待安装预览中的版本。循环依赖、非法包、API 不兼容或覆盖内置插件会阻止安装。

所有包先校验，持久化使用一个批量事务。解析校验失败不改变安装目录。激活失败与安装失败不同：已安装的代码可能保留并显示错误，以便更新修复或卸载。

## 依赖与插件组合

| 清单声明                | 用户能观察到的行为                                             |
| ----------------------- | -------------------------------------------------------------- |
| `extensionDependencies` | 消费者激活前必须启用并成功激活其提供者；提供者失败会阻止消费者 |
| `extensionPack`         | 一次安装相关成员；成员的运行、停用和卸载独立管理               |

例如“段落总结”依赖“论文词汇服务”：应同时提供两个包；不能只安装消费者并期待在线补齐。停用词汇服务会列出需要一起停用的消费者。启用消费者会一起启用所需的已安装依赖。

卸载提供者会列出全部已安装消费者，包括已经停用的消费者；确认后可一起卸载。若其中存在内置插件，宿主拒绝卸载。卸载插件组合不会自动卸载成员。

## 更新、重启与状态

重新选择相同 ID 的新版包即可更新。预览显示版本变化，降级也明确标记。更新按消费者先停止、提供者先激活的顺序处理受影响插件。

| 状态            | 含义与处理                                       |
| --------------- | ------------------------------------------------ |
| 未激活          | 已安装，等待自己的激活事件，例如打开论文         |
| 激活中          | 正在加载、注册资源或等待依赖                     |
| 已启用 / active | 激活完成；界面可能只在阅读器或相应视图中出现     |
| 已停用          | 用户停用，代码不运行，设置和状态保留             |
| 依赖受阻        | 按显示的依赖路径处理缺失、停用、循环或提供者失败 |
| 错误            | 查看错误，更新修复包，或重启该插件               |

“重启插件”重载目标及其消费者；“重启插件宿主”（英文 Restart extensions）处理全部插件作用域，按激活条件恢复。它不会刷新页面、重启应用、重新创建阅读会话或取消本体聊天。插件自己的请求与视图可因重载结束。

## 命令、快捷键与插件配置

阅读工具栏的搜索按钮或 Ctrl+Shift+P（macOS 为 Cmd+Shift+P）打开命令面板，输入标题或命令 ID 搜索。灰色命令表示当前条件未满足，例如尚未打开论文；菜单和快捷键也会按插件声明的条件变化。

在命令面板切换“键盘快捷键”，输入 ctrl+alt+b 这样的单个组合键，离开输入框即保存；恢复默认删除自定义覆盖。输入框内默认不触发插件快捷键。当前不支持连续两步组合。

“设置 → 插件”显示插件声明的布尔、数值、枚举、文本或 JSON 配置。修改后点击保存才生效，恢复默认同样会持久保存。复杂插件也可能提供独立设置栏目。配置和快捷键覆盖在重启插件后保留。

插件可使用宿主选择框、输入框和进度通知。用户取消选择/输入不会提交；可取消的任务有取消按钮。停用插件关闭其待处理交互，本体阅读与聊天继续运行。

## 内置插件与数据

选区翻译预装，可以关闭，不能卸载或被社区包覆盖。停用后翻译工具和设置退出工作台，本体阅读、OCR 配置和问答继续可用。

卸载外部插件移除安装代码，保留它命名空间内的设置与状态。缓存管理不清理安装目录；清除整个浏览器站点数据则属于更大范围的数据删除，见[数据与缓存](data-and-cache.md)。

## 视图与阅读状态

左右侧栏与底部 panel 支持关闭、重新展开、移动位置和调整尺寸。statusbar 是独立状态行。关闭一个视图通常不卸载整个插件；视图相关请求随关闭取消。

设置页覆盖并保留底下的工作区。已安装插件如果只在 `onDocumentOpen` 激活，应打开论文后再查看它的树、背景或状态项，而不是反复重启本体。

卡死的社区 Worker 会被宿主检测并终止，消费者一起停止，无关插件和本体继续运行。错误处理见[插件排查](troubleshooting.md#插件安装与运行)。
