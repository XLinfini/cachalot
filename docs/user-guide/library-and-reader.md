# 文献库与阅读

[文档目录](../README.md) · 相关：[选区翻译](translation.md)、[数据与缓存](data-and-cache.md)

## 导入与文档身份

通过导入按钮选择 PDF，或将 PDF 拖入应用。文档 ID 使用原始文件内容的 SHA-256；相同内容重复导入复用已有文献记录，首次导入时间与后续阅读更新时间分开保存。文献标题优先读取 PDF 元数据，缺失时使用文件名。

首页卡片预览由 PDF.js 单独生成。预览可再生，清除预览缓存不会删除原 PDF。

## 分类、收藏、搜索与排序

| 操作         | 行为                                                           |
| ------------ | -------------------------------------------------------------- |
| 创建普通分类 | 名称去除两端空白，最多 80 个字符，不能与已有分类或内置分类重名 |
| 移动论文     | 每篇论文归属于一个普通分类；移动不改变收藏状态                 |
| 删除普通分类 | 论文回到未分类，不删除 PDF、会话或缓存                         |
| 收藏论文     | 加入独立的收藏视图；与普通分类并存                             |
| 最近阅读     | 根据最近 30 天的文献更新时间过滤                               |
| 搜索         | 在当前过滤范围内按标题和文件名检索                             |
| 排序         | 名称或首次导入时间，各有升序与降序；偏好保存到当前设备         |

名称排序使用当前界面语言并支持数字自然排序。搜索、分类与排序只改变展示，不修改文档内容。

删除论文会移除应用中的文献及其会话，不等于删除你最初选择的外部文件。删除分类与删除论文是两种不同操作。

## 连续阅读与导航

页面在一个纵向阅读区域中连续排列。当前页由可见位置更新，关闭后可恢复保存的阅读页码。缩略图、页码输入与翻页按钮用于跳转；缩放尽量保留当前阅读位置。

“目录”读取 PDF 自带的 outline。没有原生目录的论文可能显示空目录；文档分析中的推断章节目前不是额外的自动目录功能。

左侧来源导航、本体右侧问答与插件注册的左右侧栏、底部面板是不同区域。插件视图可关闭、重新展开、移动和调整尺寸；[插件视图说明](extensions.md#视图与阅读状态)解释其生命周期。

## 版面核对

“版面”开关展示检测区域，帮助发现双栏顺序、图注、公式或表格识别问题。分析分阶段进行：原生文字先可用，版面与文档结构逐页补齐。关闭论文后重新打开，会复用兼容缓存并补齐缺失阶段。

检测框与标题、图注关系都是推断结果。存在误判时，先对照原 PDF；文字模式可精确选取原生文字，但不会自动修复文档结构。纯扫描页尚无全文 OCR。

## 操作保持范围

打开设置会保留阅读工作区和本体聊天的挂载。安装、更新或重启插件不会刷新页面、重启本体或重新创建文档分析会话。重启选区翻译插件会结束它自己的活动请求与注册视图；本体问答不随之结束。
