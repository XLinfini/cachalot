# 数据与缓存

[文档目录](../README.md) · 内部实现：[缓存管理](../architecture.md#缓存管理)

## 用户数据和可再生数据

原始 PDF、文献分类/收藏/进度、聊天与附图、模型配置、密钥、偏好、插件安装代码及插件状态属于用户数据。页面提取、版面观测、文档语义、文字索引、预览和公式候选属于可再生缓存。

Heron 权重、PDFium 和 PDF.js 是共享应用资源；它们不属于文献缓存分类。

## 六类缓存

打开“设置 → 缓存管理”，查看各类别的记录数和内容字节数，选择需要清理的一类并确认。清除作用于所有论文和旧版本缓存，不只是当前论文。

| 类别           | 清除后如何恢复                             |
| -------------- | ------------------------------------------ |
| PDF 原生提取   | 重新打开论文时由 PDFium 提取字符与对象     |
| 版面分析       | 重新运行 Heron，可以复用兼容原生数据       |
| 文档语义       | 从事实与原始观测重新组装结构               |
| 问答文字索引   | 从已有分析或新的原生提取重新建立           |
| 论文首页预览   | 文献库需要时由 PDF.js 再渲染               |
| 公式裁图与 OCR | 选取时重新裁图，必要时再次请求已配置的 OCR |

公式原图和 OCR 候选作为同组记录清理，再识别可能产生服务商费用。清理缓存不删除论文、会话、图片、模型配置、密钥或插件。

统计是已保存内容的字节估算，不包含数据库页、索引等开销；图像按所存 Base64 字符串计数。清理后空闲空间可被数据库复用，不保证磁盘文件立即缩小。当前打开的 canvas、页面 Promise 和分析会话是临时内存，清理持久缓存不等于立即卸载阅读器；需要验证重建时可关闭并重开论文。

## 桌面与浏览器存储

| 数据                         | Tauri 桌面                                 | 浏览器预览                                             |
| ---------------------------- | ------------------------------------------ | ------------------------------------------------------ |
| 原 PDF                       | 应用数据目录的 `documents/`                | IndexedDB `cachalot-pdfs`                              |
| 文献、分类、聊天、模型和偏好 | `cachalot.sqlite3`                         | localStorage；聊天图像另在 IndexedDB                   |
| 密钥                         | 操作系统 keyring                           | `cachalot-provider-keys`，加密内容与不可导出 CryptoKey |
| 事实与观测                   | SQLite `page_analysis`                     | `cachalot-analysis`                                    |
| 文档语义                     | SQLite `document_semantics`                | `cachalot-semantics`                                   |
| 预览与公式                   | SQLite 设置项 / `page_analysis`            | `cachalot-previews` / `cachalot-formulas`              |
| 插件安装代码                 | Webview 的 IndexedDB `cachalot-extensions` | 当前 origin 的同名 IndexedDB                           |
| 插件状态与配置               | 通过本体设置存储，插件 ID 命名空间         | 同一逻辑，底层为 localStorage                          |

桌面应用数据目录由 Tauri 按平台解析，应用标识为 `app.cachalot.reader`，不要把开发机的绝对路径复制成所有平台的路径。桌面安装代码也不在 SQLite 中，复制一个数据库文件不代表备份了所有内容。

## 浏览器数据身份与恢复

浏览器数据属于 origin 与 profile。`localhost` 和 `127.0.0.1`、不同端口、另一个 profile、桌面 Webview 都不是同一个数据环境。

普通刷新可恢复已提交的数据；清除站点数据会删除 PDF、密钥和插件等用户数据，不能作为常规的插件排查步骤。隐私会话退出后的保留行为由浏览器决定。当前没有一键备份/导入迁移或跨设备同步功能，应保留外部原 PDF 和本地插件包。

缓存清除通过写入代次屏蔽旧后台任务的回写，但另一独立浏览器标签页仍可能正常重建该 origin 的缓存。共享站点使用时，大小变化不一定意味着清理失败。
