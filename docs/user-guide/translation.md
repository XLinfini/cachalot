# 选区翻译

[文档目录](../README.md) · 前置：[模型与 OCR](models-and-ocr.md) · 相关：[插件管理](extensions.md)

选区翻译是当前预装插件。本体提供文档、来源、OCR 和模型能力，插件决定选取范围、背景、翻译协议和结果窗口。停用插件后仍可阅读论文和使用本体问答。

## 两种选取方式

| 模式 | 适合的任务                             | 输出范围                                 |
| ---- | -------------------------------------- | ---------------------------------------- |
| 框选 | 翻译完整段落、标题等文本单元或行间公式 | 仅接受完全包含在手势框内的语义单元       |
| 文字 | 翻译句子或精确选择的原生文字           | 使用实际选中的字符，不自动补全段落或公式 |

框选时鼠标手势是**蓝色边框、无填充**；实际命中的单元显示**紫色边框、半透明填充**。部分覆盖不会命中。段落中的行内公式属于该段落，所需范围包含文字和公式的实际边界。

正文之外的标题、图注、列表等可按完整文本单元命中；图、表、页眉、页脚不作为正文翻译单元。框选依赖已完成的页面版面分析，原生回退行不足以证明完整段落。没有完整单元时不显示“翻译选区”。

当前手势在单页内完成，不是跨页拖选或全文翻译。文字模式依赖 PDF 中可提取的字符；扫描图像中的文字目前不具备这个入口。

## 翻译步骤

1. 在阅读器的模型菜单选择用于翻译的语言模型。
2. 选择内容，核对紫色命中框或文字高亮。
3. 点击“翻译选区”。插件先准备来源和公式，再请求翻译。
4. 在三栏窗口对照原 PDF 截图、复建原文与译文。遇到公式候选问题，查看提示并决定是否重试或保留原图。
5. 使用结果窗口的复制动作取得译文；复制不是生成整篇 PDF 文件。

关闭结果窗口会取消该视图的请求；停用或重启插件会结束它的全部请求。用户设置和状态保留。

## 背景上下文与输出范围

插件从**同一份文档语义快照**取得已识别的论文标题、摘要、章节路径、所处与相邻段落，并限制长度。这些背景帮助确定学术语境，不能扩大待翻译范围。

文档分析不完整时，背景也可能不完整。找不到可信的显式摘要标签时不生成摘要；没有强制术语表，也不把之前每次翻译自动串成同一会话。各次翻译仍需对照术语与原文。

界面切换成英语不会自动切换翻译目标语言。翻译提示词在“设置 → 阅读与翻译”编辑；当前默认围绕简体中文学术翻译组织。

## 公式如何保留

| 来源                                     | 处理                                     |
| ---------------------------------------- | ---------------------------------------- |
| 可由原生字形与几何重建的简单公式         | 生成 LaTeX 候选并做检查                  |
| 完整的复杂公式                           | 使用已选择的独立 OCR，或图像模型回退识别 |
| 识别失败、候选不合格、精确选取的部分公式 | 保留原始区域图片                         |

原文与译文使用相同公式候选。翻译模型处理正文与位置标记，不应改写公式；标记缺失、重复或顺序改变时会提示错误。远端 OCR 候选与原图按模型和规则版本缓存，合格缓存可复用。

语法及字符检查可以发现部分错误，不能证明数学语义正确。原始 PDF 是核对依据。当前网页中的 KaTeX 展示不等于原 PDF 公式的矢量迁移；矢量裁剪是开发接口，也不代表已实现全文 PDF 重排导出。

出现问题时看[翻译与公式排查](troubleshooting.md#翻译与公式)，开发实现见[架构](../architecture.md#公式定位语义与保真)。
